# 로컬 특징 파일

이 폴더에는 팀에서 별도로 공유받은 다음 두 파일을 배치합니다.

- `bottle_train_features.pt`: 정상 학습·검증 특징
- `bottle_test_features.pt`: 테스트 특징·라벨·정답 마스크

파일은 Google Drive 등으로 별도 공유하며 Git에 추가하지 않습니다.
프로젝트 루트의 `.gitignore`에서 모델·배열 파일과 이 폴더의 데이터 파일을 제외합니다.
이 안내 문서만 Git으로 공유합니다. 파일이 없어도 원본 데이터로 앱의 이미지 비교 모드를 사용할 수 있습니다.

앱·노트북·평가·시간 측정은 [공통 분할 목록](../splits/bottle.json)을 사용합니다.
분할 JSON은 재현에 필요한 작은 설정 파일이므로 Git에 포함합니다.
